Hashing Techniques in C

This repository contains C programs demonstrating different hashing and collision resolution techniques.

📌 Programs Included

- Linear Probing – Resolves collisions by checking the next available position sequentially.
- Quadratic Probing – Resolves collisions using quadratic increments to find an empty position.
- Double Hashing – Uses two hash functions to calculate the next position when a collision occurs.

🛠️ Implementation Details

- Language: C
- Hash Table Size: 11
- Sample keys are used to demonstrate the hashing techniques.
- Each program displays the final hash table with the corresponding index and stored key.

📂 Contents

├── Linear Probing
├── Quadratic Probing
└── Double Hashing

🎯 Purpose

The programs are designed for learning and understanding hash tables, hash functions, and collision resolution techniques in Data Structures.
